Architecture

Engineered for zero background overhead.

01 / NSPasteboard.changeCount

Lightweight Change-Count Polling

Polls the integer NSPasteboard.general.changeCount with 150ms timer tolerance so macOS coalesces wakeups—consuming zero CPU until you actually copy something new.

02 / Non-Activating HUD

Never Steals Focus

Runs inside a floating NSPanel with .nonactivatingPanel mask. Your active code editor, browser, or terminal stays focused so pasting via synthesized ⌘V is immediate.

03 / Multi-Representation Capture

Text, RTF, Links, Colors & Files

Automatically classifies plain text, RTF formatting, URLs, hex/RGB color codes (rendering inline color swatches), screenshots, and local Finder file references.

04 / ImageIO Subsampling

Bounded Memory Footprint

Generates downsampled thumbnails via CGImageSourceCreateThumbnailAtIndex without decoding full 4K bitmaps into memory, preventing RAM bloat over multi-week uptime.

05 / Privacy & Concealed Types

Password Manager Aware

Respects standard transient and concealed pasteboard markers so sensitive credentials from 1Password, Keychain, and Bitwarden can be excluded or cleared in one click.

06 / Atomic Persistence

Debounced Disk Writes

History is persisted asynchronously to ~/Library/Application Support/Klipboard on a background serial queue with automatic pruning beyond 200 items.

Keyboard Navigation

Every action is reachable without touching the mouse.

Summon or dismiss Klipboard ⌥ V or ⌘ ⇧ V
Navigate clipboard history ↑ ↓
Paste selected item into active app ↵ Return
Copy to clipboard without pasting ⌥ ↵
Pin or unpin selected item ⌘ P
Delete selected item from history ⌘ ⌫
Switch filter categories ⌘ 1 – ⌘ 6

Installation

Install in one command (skips Gatekeeper popup) or via the drag-and-drop DMG.

Option A — 1-Line Terminal Install (Recommended, No Gatekeeper Warning)
curl -fsSL https://klipboard-beryl.vercel.app/install.sh | bash
Option B — Drag-and-Drop DMG Installer
  1. Download Klipboard-0.1.0.dmg (1.3 MB) and open the disk image.
  2. Drag Klipboard.app into the Applications folder shortcut.
  3. If macOS shows “Klipboard” Not Opened, either click Done → System Settings → Privacy & Security → Open Anyway, or run once in Terminal:
xattr -cr /Applications/Klipboard.app && open /Applications/Klipboard.app
