Your Mac's Clipboard, Supercharged.

Summon your entire clipboard history from anywhere with ⌥V or ⌘⇧V. Built natively in Swift with near-zero memory & CPU overhead.

⬇ Download Klipboard-0.1.0.dmg View on GitHub

Drag-and-drop macOS Disk Image (.dmg) • 1.3 MB • Free & Open Source (MIT)

⚡ Instant Spotlight Panel

Press ⌥V or ⌘⇧V in any app to open the floating glass panel, search clips, and hit Return to paste directly.

📎 Every Format

Captures plain text, rich text (RTF), URLs, images, files (with Reveal in Finder), and color swatches automatically.

🪶 Featherweight by Design

Uses timer-coalesced polling and ImageIO thumbnail downsampling so idle CPU stays at 0.0% and RAM stays tiny.

Quick Install (Drag & Drop)

  1. Download and open Klipboard-0.1.0.dmg.
  2. Drag Klipboard.app into the Applications folder inside the DMG window.
  3. Open Klipboard from /Applications or Spotlight (if Gatekeeper prompts on first launch, run xattr -cr /Applications/Klipboard.app in Terminal).
